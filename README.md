# tiktok-iqd-earnings-calculator

A Python tool designed to calculate net TikTok coin earnings for content creators in Iraq in both USD and IQD. By entering the number of gifted coins (e.g., 5,000 coins), the program calculates the creator's net share in USD, deducts standard PayPal withdrawal fees, and scrapes the latest official and parallel market USD-to-IQD exchange rates directly from iraqsm.com to display the final net payout in Iraqi Dinars clearly and accurately.

# Installation

Clone the repository:
   ```bash
   git clone [https://github.com/iqtnt/tiktok-iqd-earnings-calculator.git](https://github.com/iqtnt/tiktok-iqd-earnings-calculator.git)
   cd tiktok-iqd-earnings-calculator
   ```
Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```
# Usage
Run the script from your terminal:
```bash
  python main.py
   ```
